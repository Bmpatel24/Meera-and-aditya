૧. સૌથી સરળ રીત (Windows વપરાશકર્તાઓ માટે):
   - ફોલ્ડરમાં રહેલી "1-CLICK-PREVIEW-FOR-WINDOWS.bat" ફાઈલ પર DOUBLE CLICK કરો.
   - આપમેળે લોકલ સર્વર http://localhost:8080 શરૂ થશે અને તમારા બ્રાઉઝરમાં વેબસાઇટ ખુલી જશે.
   - બધા જ ફોટા, રોયલ ગેટવે ઓપનિંગ, સિનેમેટિક વિડિયો, મ્યુઝિક અને એનિમેશન ૧૦૦% પરફેક્ટ કામ કરશે!

૨. ડાયરેક્ટ બ્રાઉઝર ઓપન:
   - "double-click-to-preview.html" અથવા "index.html" ફાઈલ પર Double Click કરો.

૩. Mac કમ્પ્યુટર માટે:
   - "1-CLICK-PREVIEW-FOR-MAC.command" પર Double Click કરો.

【 ભાગ ૨: GitHub પર આખો પ્રોજેક્ટ અને ફોલ્ડર અપલોડ કરવાની રીત 】
===============================================================

ગિટહબ પર આખો 'assets' ફોલ્ડર ૧૦૦% અપલોડ થઈ જાય છે:

★ રીત ૧ - GitHub વેબસાઇટ પર Drag & Drop (માઉસથી ખેંચીને મૂકવું):
૧. https://github.com પર નવું Repository બનાવો (દા.ત. meera-aditya-wedding).
૨. "Add file" -> "Upload files" પર ક્લિક કરો.
૩. તમારા કમ્પ્યુટરમાંથી 'assets' ફોલ્ડર અને 'index.html', 'vercel.json', 'package.json', 'README.md' બધી જ ફાઈલો સિલેક્ટ કરીને માઉસ વડે સીધી GitHub ના બ્રાઉઝર પેજ પર Drag & Drop (ખેંચીને) મૂકી દો.
૪. GitHub આપમેળે 'assets' ફોલ્ડર બનાવીને તમામ વિડિયો અને ફોટા અપલોડ કરી દેશે!
૫. નીચે "Commit changes" બટન પર ક્લિક કરો.

★ રીત ૨ - Git ટર્મિનલ કમાન્ડ્સ:
   git init
   git add .
   git commit -m "Meera & Aditya Wedding Invitation"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/meera-aditya-wedding.git
   git push -u origin main

૫. "Deploy" બટન પર ક્લિક કરો!
૬. તમારી રોયલ વેડિંગ વેબસાઇટ સુંદર લિંક સાથે લાઈવ થઈ જશે (દા.ત. https://meera-aditya-wedding.vercel.app)!

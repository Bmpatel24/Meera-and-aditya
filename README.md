# Meera & Aditya — Royal Wedding Invitation ✨
> An extraordinary, luxury cinematic Indian wedding invitation for the union of **Meera Kapur & Aditya Singhvi** in Udaipur, Rajasthan.

---

## 🌟 Features Included
- 🚪 **Royal Gateway Door Opening Transition**: Interactive animated cover card with grand gateway opening effect.
- 🎬 **Cinematic Video & Ambient Audio**: Luxury video playback with audio mute/unmute controls.
- 🌺 **Golden Canvas Particle & Petal Animations**: Rich golden aesthetic with floral motifs and royal ornaments.
- 📅 **Multi-Day Royal Events Timeline**: Mehendi, Haldi, Sangeet Night, Sacred Mandap Wedding, and Reception.
- 🏰 **Heritage Venue Showcase**: The Oberoi Udaivilas, Udaipur with interactive map links and accommodation details.
- 📸 **Editorial Photo Gallery**: High-resolution couple portraits and royal celebration snapshots with modal preview.
- 💌 **Interactive RSVP & Guest Blessings Form**: Instant guest confirmation and blessing registry.
- ⏳ **Live Countdown Timer**: Real-time counter ticking down to the royal wedding date.
- 📱 **100% Fully Responsive**: Pixel-perfect layout across Mobile, Tablet, and Desktop.

## 🚀 GitHub Upload & Vercel Deployment (લાઈવ મુકવા માટે)

This repository is **100% pre-configured and optimized for Vercel, Netlify, and GitHub Pages**.

### Step 1: Push to GitHub
```bash
git init
git add .
git commit -m "Meera & Aditya Royal Wedding Invitation"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/meera-aditya-wedding.git
git push -u origin main
```

### Step 2: Deploy to Vercel (Free & Instant)
1. Go to [Vercel](https://vercel.com) and log in with your GitHub account.
2. Click **Add New...** → **Project**.
3. Import your **`meera-aditya-wedding`** repository.
4. Framework Preset: **Other** (Static HTML).
5. Click **Deploy**.
6. Your luxury wedding website is live within seconds (e.g. `https://meera-aditya-wedding.vercel.app`)!

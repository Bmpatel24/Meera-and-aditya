# The Royal Wedding of Meera & Aditya

An ultra-luxurious, cinematic royal wedding web invitation application crafted with traditional Indian palace elegance, bespoke animations, and interactive ceremonial chapters.

## Project Structure
- `src/components/InvitationCoverPage.tsx` - Royal Wax Seal Envelope Cover (Page 1)
- `src/components/CinematicVideoPage.tsx` - Full-Screen Cinematic Video Hero (Page 2 Header)
- `src/components/BlessingSection.tsx` - Auspicious Sanskrit Invocations
- `src/components/CountdownRevealSection.tsx` - Live Countdown & Scratch-to-Reveal Card with Flower Celebration
- `src/components/StorySection.tsx` - The Eternal Love Story Chapters
- `src/components/InvitationCardSection.tsx` - Royal Wedding Card (Shubh Vivah Patrika)
- `src/components/CelebrationsSection.tsx` - Single-Line Vertical Ceremony Cards (Mehndi, Haldi, Sangeet, Pheras, Reception)
- `src/components/GallerySection.tsx` - Vertical Heritage Royal Portrait Gallery
- `src/components/VenueSection.tsx` - The Oberoi Udaivilas, Lake Pichola Destination Sanctuary
- `src/components/ClosingSection.tsx` - Auspicious Benediction & Peace Mantra
- `src/components/Ornaments.tsx` - 24K Gold Coin Medallion (`M & A`), Botanical Lotus Separators, Manglik Glyphs
- `src/components/PetalCanvas.tsx` - Drifting Rose Petals & Gold Dust Ambient Canvas
- `src/assets/` - All media assets (videos, audio, images, icons)

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Runs at `http://localhost:3000`.

### 3. Production Build
```bash
npm run build
```
Creates production-ready static assets in the `dist/` directory.
